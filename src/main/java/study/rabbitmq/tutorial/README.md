## RabbitMQ 튜토리얼
RabbitMQ는 바이너리 데이터 덩어리( 메시지)를 수신, 저장 및 전달하는 메시지 브로커입니다.<br/>
기본 포트는 5672를 사용합니다.<br/>
메시지를 생산해서 보내는것을 Producer(생산자)라고 칭합니다.<br/>
큐는 RabbitMQ에서 메시지를 저장하는 저장소를 의미합니다.
메시지는 RabbitMQ와 애플리케이션을 통해 흐르지만, 실제로는 큐 안에만 저장될 수 있습니다.<br/>
큐는 호스트의 메모리 및 디스크 용량에 따라 저장 용량이 제한되고 기본적으로는 대용량 메시지 버퍼와 같습니다. <br/>
생산된 메시지를 소비하는것은 Consumer(소비자)라고 칭합니다.<br/>
